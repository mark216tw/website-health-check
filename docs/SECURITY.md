# 安全性政策

## 1. 支援版本

目前維護的版本：

| 版本 | 支援 |
|---|---|
| 1.0.0-prerelease | 是（測試版本） |

Pre-release 使用 Android Debug 金鑰簽署，**不適合正式上線或處理敏感資料**。

## 2. 權限

App 宣告以下權限：

| 權限 | 用途 |
|---|---|
| `INTERNET` | 執行網站健康檢查 |
| `ACCESS_NETWORK_STATE` | WorkManager 網路連線條件 |
| `POST_NOTIFICATIONS` | Android 13+ 發送異常／恢復通知 |

App 不需要定位、相機、麥克風、聯絡人或儲存空間權限。

## 3. 資料儲存

- 網站設定與檢查紀錄儲存在本機 Room 資料庫。
- 偏好設定儲存在本機 SharedPreferences。
- 無帳號系統、無雲端同步、無分析或遙測。
- CSV 由使用者透過系統文件選擇器指定位置匯出。
- 解除安裝 App 後，本機資料會一併移除（Android 備份行為依系統設定而異）。

## 4. 網路安全

- 預設驗證 TLS 憑證，**不繞過 SSL 錯誤**。
- 憑證、TLS 握手或主機名稱錯誤會記錄為 `TLS` 失敗。
- App 允許檢查 HTTP 網站，因此 Manifest 允許明文流量。
- 編輯 HTTP 網址時會顯示「內容未加密」警告。
- 使用者應優先監控 HTTPS 網站。
- 本 App 不傳送檢查資料到任何第三方服務。

## 5. 內容檢查

- 只讀取回應前 1 MB。
- 只做字串包含比對，不執行 JavaScript、不渲染 HTML、不執行頁面內容。
- 不應將本 App 作為網頁內容安全掃描工具。

## 6. 簽署與發行

- `1.0.0-prerelease` 使用 Android Debug 金鑰簽署。
- 正式發行前必須：
  - 建立專屬 release keystore
  - 妥善保管金鑰與密碼
  - 更新 `signingConfig`
  - 遞增 `versionCode`
  - 考慮啟用 R8 並完成實機回歸測試
- 請勿在儲存庫中提交 keystore、密碼、API token 或其他機密資料。
